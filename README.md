**Noah’s Ark Home Services**

## Overview
A Django-based home-service booking platform that connects customers with service providers for various household services. The system provides separate dashboards and workflows for customers, service providers, and administrators, including service management, booking, payments, reviews, and rework requests.

## Features
- Customer registration and login
- Service provider login and dashboard
- Admin dashboard and management
- Dynamic service and service-category management
- Service provider management
- Service availability checking
- Normal and emergency service booking
- Booking management and cancellation
- Online payment processing
- Razorpay payment integration
- Customer reviews and ratings
- Service rework requests
- Customer enquiries/contact management
- Provider booking management
- Provider service management
- Admin management of customers, providers, bookings, payments, reviews, and enquiries
- Responsive user interface

## User Roles
**3 User Roles:**
1. **Admin** – Manages customers, providers, services, bookings, payments, reviews, and enquiries.
2. **Customer** – Registers, browses services, books services, makes payments, reviews services, and requests rework.
3. **Service Provider** – Manages assigned bookings, services, and service-related activities.

## Technology Stack
- **Backend:** Python, Django
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Database:** SQLite
- **Payment Gateway:** Razorpay
- **Version Control:** Git / GitHub

## Database
**SQLite**
The application uses Django ORM for database operations and includes models for users/profiles, services, service sections, providers, customers, bookings, payments, reviews, and enquiries.

## Payment Integration
**Razorpay**
Integrated Razorpay for online customer payments during the service booking process, including payment initiation and callback/payment verification workflows.
